# Детальное объяснение MainWindow.h и MainWindow.cpp

## MainWindow.h - Заголовочный файл

### Секция 1: Защита от множественного включения и базовые включения

```cpp
#pragma once
```
**Принцип:** Директива препроцессора, предотвращающая множественное включение заголовочного файла в единицу компиляции. Это стандартная практика в C++ для избежания ошибок переопределения классов.

**Значение для программы:** Гарантирует, что определение класса `MainWindow` будет включено только один раз, даже если файл включен в нескольких местах. Это критично для корректной компиляции.

---

```cpp
#include "controllers/CarsCatalogController.h"
```
**Принцип:** Включает полное определение класса `CarsCatalogController`, который управляет каталогом автомобилей. Это необходимо, так как `MainWindow` хранит `std::unique_ptr<CarsCatalogController>`.

**Значение для программы:** `CarsCatalogController` - это контроллер, который обрабатывает бизнес-логику фильтрации и загрузки автомобилей. Без него главное окно не сможет работать с каталогом.

---

```cpp
#include <QLabel>
#include <QMainWindow>
#include <QScrollArea>
#include <QWidget>
```
**Принцип:** Включает базовые классы Qt Widgets, которые используются как члены класса или базовый класс. `QMainWindow` - базовый класс для главного окна приложения.

**Значение для программы:** 
- `QMainWindow` предоставляет структуру главного окна с меню, панелями инструментов и центральным виджетом
- `QWidget` - базовый класс для всех UI элементов
- `QLabel` - для отображения текста
- `QScrollArea` - для прокручиваемых областей

---

```cpp
#include <memory>
```
**Принцип:** Включает стандартную библиотеку для умных указателей (`std::unique_ptr`, `std::make_unique`).

**Значение для программы:** Позволяет использовать современный C++ подход к управлению памятью, автоматически освобождая ресурсы при уничтожении объекта.

---

### Секция 3: Определение класса MainWindow

```cpp
class MainWindow : public QMainWindow {
```
**Принцип:** Наследование от `QMainWindow` - стандартного класса Qt для главных окон приложений. Это обеспечивает структуру окна с меню, панелями и центральным виджетом.

**Значение для программы:** `MainWindow` получает всю функциональность главного окна Qt, включая управление меню, панелями инструментов, статусной строкой и центральным виджетом.

---

```cpp
  Q_OBJECT
```
**Принцип:** Макрос Qt Meta-Object System, который генерирует мета-информацию о классе для системы сигналов и слотов. Это необходимо для использования `signals`, `slots`, `Q_EMIT`, `Q_SIGNALS`, `Q_SLOTS`.

**Значение для программы:** Позволяет использовать механизм сигналов и слотов Qt для связи между объектами. Без этого макроса нельзя использовать `connect()` для методов этого класса.

### Секция 4: Публичный интерфейс

```cpp
public:
  explicit MainWindow(QWidget *parent = nullptr);
```
**Принцип:** 
- `explicit` предотвращает неявные преобразования типов при создании объекта
- `parent = nullptr` означает, что окно может быть создано без родительского виджета (главное окно приложения)

**Значение для программы:** Конструктор создает главное окно приложения. `explicit` гарантирует, что нельзя случайно создать `MainWindow` из другого типа.

---

```cpp
  ~MainWindow() override;
```
**Принцип:** Виртуальный деструктор с `override` гарантирует правильное уничтожение объекта при полиморфном удалении.

**Значение для программы:** Обеспечивает корректное освобождение ресурсов при закрытии приложения.

### Секция 16: currentFilters() - Получение текущих фильтров

- Упрощает передачу фильтров в контроллер

## Общие принципы архитектуры

### 1. Разделение ответственности
- **UI (MainWindow)** - только отображение и взаимодействие с пользователем
- **Контроллер (CarsCatalogController)** - бизнес-логика фильтрации
- **Модель (RentalsModel)** - данные для таблицы
- **База данных (Database)** - хранение данных

### 2. Управление памятью
- **Умные указатели (`unique_ptr`)** - для автоматического управления памятью
- **Родительские виджеты** - Qt автоматически удаляет дочерние виджеты
- **Явное удаление** - только для `rentalsModel_`, который не имеет родителя

### 3. Сигналы и слоты
- **Слабая связанность** - объекты не знают друг о друге напрямую
- **Реактивность** - автоматическое обновление при изменениях
- **Lambda-функции** - для простых обработчиков

### 4. Обработка ошибок
- **Исключения** - для критических ошибок (база данных)
- **Проверки** - для валидации данных (ID пользователя)

### 5. Пользовательский опыт
- **Автоматический вход** - сохранение сессии
- **Реактивные фильтры** - мгновенное обновление
- **Визуальная обратная связь** - обновление UI при действиях
